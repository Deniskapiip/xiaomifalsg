# Ссылка, вставка и автозаполнение товара

## Вставка и подсветка

Кнопка «Вставить» пробует получить текст из буфера. Если Telegram или браузер запрещает чтение, открывается окно ручной вставки: удерживайте поле и выберите «Вставить», затем нажмите «Использовать ссылку». На компьютере можно использовать Ctrl+V или ⌘V. Разрешён полный китайский текст «Поделиться»: одна однозначная ссылка выделяется автоматически.

После нажатия «Далее» незаполненные или неверные обязательные поля три раза пульсируют красным, а первое получает фокус. После исправления красная подсветка пропадает. Название и комментарий остаются необязательными. При системной настройке уменьшения движения сохраняется красная рамка без анимации.

## Что подключено

После ввода ссылки приложение автоматически запрашивает данные товара у backend. Необязательный адаптер OneBound поддерживает Taobao/Tmall, 1688 и Goofish/Xianyu: название, до восьми фотографий, цену в юанях и варианты товара.

Название и цена подставляются только в пустые поля. Ручные правки, сделанные во время загрузки, сохраняются; ответ для предыдущей ссылки игнорируется. Если цены вариантов отличаются, нужно выбрать конкретный вариант. После получения или изменения цены сразу обновляется предварительный выкуп в рублях по текущему курсу и комиссии. Доставка рассчитывается отдельно по тарифу и весу.

Перед оформлением проверьте цену: она может отличаться для авторизованного покупателя, акции или выбранного варианта. Окончательный расчёт заказа по-прежнему подтверждает backend.

**Для настоящих данных нужны собственные API key и secret OneBound. Без них доступен ручной ввод.** Мы не создавали аккаунт, не покупали доступ и не проверяли запросы на живом аккаунте. Источник платный; согласно документации, ошибочные вызовы тоже могут тарифицироваться. Посмотрите текущие условия и возможность пробного доступа перед оплатой.

## Где взять ключи

1. Зарегистрируйте собственный аккаунт в [консоли OneBound](https://console.open.onebound.cn/).
2. Проверьте доступ и стоимость методов `item_get` для нужных площадок: `goodfish`, `taobao`, `1688`.
3. В существующем файле `G:\taoji-cargo\.env` добавьте:

```dotenv
ONEBOUND_API_KEY=ВАШ_API_KEY
ONEBOUND_API_SECRET=ВАШ_API_SECRET
```

4. Перезапустите backend. После этого ввод ссылки запускает запрос к сервису. Чтобы отключить импорт, очистите оба значения и снова перезапустите backend.

Ключи остаются на сервере. Не отправляйте файл `.env` в чат и не добавляйте его в архив.

Короткие ссылки `m.tb.cn` разрешаются в адрес карточки только через разрешённые домены. Если площадка требует вход, показывает проверку или не отдаёт ID/цену, приложение предлагает ручное заполнение. Получение данных для любой произвольной ссылки не гарантируется.

## Как поставить обновление при работающем ngrok

1. Оставьте окно ngrok открытым. В окне backend нажмите Ctrl+C.
2. Распакуйте обновление в `G:\` с заменой файлов проекта `taoji-cargo`. Готовый `frontend/dist` уже включён.
3. Сохраните свои `.env`, `.venv`, `data`, `backups` и настройку ngrok. Новые зависимости и миграция базы для этого обновления не нужны.
4. Запустите backend с текущим HTTPS-адресом ngrok:

```powershell
cd G:\taoji-cargo
$taojiNgrokUrl = (Invoke-RestMethod 'http://127.0.0.1:4040/api/tunnels').tunnels | Where-Object { $_.proto -eq 'https' } | Select-Object -First 1 -ExpandProperty public_url
.\start.bat --url $taojiNgrokUrl
```

5. Закройте старое окно Mini App, отправьте боту `/app` и откройте приложение заново.

## Проверка и ограничения

Проверены ответы API на тестовых данных, варианты и цены, сохранение ручных правок, устаревшие ответы, отказ чтения буфера и работа диалога. Реальные ссылки с вашим аккаунтом OneBound, разрешения буфера и внешний вид на телефоне нужно проверить в Telegram.

Фотографии идут через ограниченный прокси изображений. Пользовательские cookies не используются; вход и антибот-проверки не обходятся. Ручное оформление доступно при недоступности источника.
