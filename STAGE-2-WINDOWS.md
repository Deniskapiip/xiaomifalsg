# Этап 2 — интерфейс клиента на Windows

Эта инструкция обновляет уже работающий проект в `G:\taoji-cargo`. Настройки, виртуальное окружение и существующие заказы сохраняются.

## Что мы сделали и зачем

Добавлен клиентский интерфейс: онбординг, главная, мастер оформления, список и карточка заказа, помощь. В карточке видны сохранённый расчёт, этапы доставки и история. Статусы «В пути до получателя» и «Доставлен» берутся из backend; доставленные и отменённые заказы находятся в «Завершённых».

Сейчас проверяем интерфейс в браузере на вашем ПК. Админка появится на Этапе 3; проверка настоящего запуска внутри Telegram и с телефона предстоит отдельно.

## Как проверить

### 1. Обновите файлы

В окне с работающим сервером нажмите `Ctrl+C`.

Распакуйте новый архив в `G:\` с заменой исходников всего проекта, включая `backend`. Совместите папку из архива с существующей `G:\taoji-cargo`: после распаковки должен существовать файл `G:\taoji-cargo\frontend\package.json`. Вложенная папка `G:\taoji-cargo\taoji-cargo` не нужна.

Обновление backend необходимо: `/api/calc` теперь возвращает курс, комиссию и тариф, использованные в расчёте. Без этих новых полей итоговый экран интерфейса не сможет показать полный расчёт.

Не удаляйте `.env`, `.venv` и `data`. Их нет в архиве обновления. Не запускайте настройку окружения заново и не заменяйте свой `.env` образцом `.env.example`.

Схема БД на этом этапе не менялась: дополнительных миграций не требуется. Демо-тарифы у вас уже созданы; повторно запускать seed для обновления не нужно.

### 2. Соберите интерфейс

В архив уже включена готовая сборка `frontend\dist`. Для быстрого просмотра можно перейти к шагу 3. Команды ниже нужны для проверки исходников и повторной сборки после изменений.

Откройте PowerShell и проверьте Node.js:

```powershell
node --version
npm.cmd --version
```

Рекомендуем Node.js 24 LTS. Поддерживаются Node.js 22 от 22.12, ветка 24 и версии от 26; ветки 23 и 25 не поддерживаются. Если Node.js ещё не установлен, установите LTS:

```powershell
winget install --id OpenJS.NodeJS.LTS --exact --source winget
```

После установки откройте новое окно PowerShell. Выполните:

```powershell
cd G:\taoji-cargo\frontend
npm.cmd ci
npm.cmd test
npm.cmd run build
```

`npm.cmd ci` устанавливает зафиксированные зависимости. `test` проверяет клиентскую логику. `build` проверяет TypeScript и создаёт готовый интерфейс в `frontend\dist`. Ожидается завершение всех трёх команд без ошибок.

### 3. Запустите приложение

В том же окне:

```powershell
cd ..\backend
..\.venv\Scripts\python.exe -m app.main
```

Откройте на ПК [http://127.0.0.1:8000](http://127.0.0.1:8000). Теперь по этому адресу должен появиться интерфейс. Окно сервера оставьте открытым. Локальный тестовый вход использует `.env`, который вы настроили на Этапе 1.

### 4. Пройдите сценарий

В шапке и на экране онбординга кнопка с солнцем/луной переключает светлую и тёмную темы. Проверьте оба варианта и перезагрузите страницу: выбранная тема должна сохраниться в этом браузере. Переключение темы не очищает заполненные поля мастера.

1. Пройдите или пропустите онбординг. На главной проверьте курс, четыре этапа доставки и контакты.
2. Нажмите «Рассчитать и оформить заказ». Укажите полную ссылку на товар, цену `300`, количество `1` и название для теста.
3. Выберите демо-тариф с ценой `1 800 ₽ / кг`, укажите вес `2,3`.
4. При курсе `13,5`, комиссии `6,5%` и минимуме `650 ₽` результат должен быть: товар `4 050 ₽`, комиссия `650 ₽`, выкуп `4 700 ₽`. Ориентировочная доставка — отдельно `4 140 ₽`.
5. До отправки перезагрузите страницу. Черновик должен восстановиться. Вернитесь к итоговому расчёту и оформите тестовый заказ.
6. Проверьте экран «Заказ принят», номер и карточку в «Моих заказах». Быстрое повторное нажатие не должно создавать второй заказ: отправка блокируется, а backend обрабатывает повторный ключ как тот же заказ.
7. В карточке проверьте номер, сохранённый расчёт, тариф и историю с датами МСК. Попробуйте скопировать номер и открыть товар.
8. Переключите «Активные / Завершённые». Новый заказ находится в активных. Список обновляется при возвращении в приложение и каждые 30 секунд, пока экран открыт. Завершённая вкладка может быть пустой, пока нет доставленных или отменённых заказов.
9. В «Помощи» раскройте вопросы и проверьте контакты. Кнопки менеджера и канала открывают Telegram.

Это создаёт настоящий тестовый заказ в вашей локальной БД. В тестовом режиме Этапа 1 бот отключён, поэтому уведомления в Telegram не отправляются.

## Что может пойти не так и что делать

| Проблема | Что сделать |
|---|---|
| `node` или `npm.cmd` не найдены | Установите Node.js LTS и откройте новый PowerShell. |
| Сборка сообщает о неподдерживаемой версии Node.js | Обновите установленный Node.js LTS командой `winget upgrade --id OpenJS.NodeJS.LTS --exact --source winget`, затем откройте новый PowerShell. |
| `npm ci` сообщает, что не найден `package.json` | Проверьте, что текущая папка — `G:\taoji-cargo\frontend` и архив распакован без лишней вложенной папки. |
| `npm ci` не может скачать пакеты | Проверьте интернет и повторите команду. Не удаляйте `package-lock.json`. |
| По корневому адресу всё ещё отображается сообщение об отсутствующем интерфейсе | Выполните `npm.cmd run build` в папке `frontend`, затем перезапустите backend и обновите страницу. |
| Порт 8000 занят | Остановите прежний сервер через `Ctrl+C`, затем запустите один экземпляр. |
| Браузер просит открыть приложение в Telegram | Проверьте, что сохранился `.env` с локальной настройкой Этапа 1: `DEV_MODE=true`, `BOT_ENABLED=false`, `WEBAPP_URL=http://127.0.0.1:8000`. После изменения настроек перезапустите сервер. |
| Итог отличается от примера | Сверьте текущий курс и цену выбранного тарифа. Числа в примере относятся к указанным выше настройкам. |
| Тарифы не отображаются | Проверьте, что сервер использует прежнюю БД и сохранилась папка `data`. Настройка тарифов через интерфейс появится на Этапе 3. |
| Не удалось прочитать или скопировать буфер обмена | Вставьте ссылку обычным способом; номер заказа можно выделить и скопировать вручную. Возможности буфера зависят от браузера. |
| На телефоне адрес `127.0.0.1` не открывает приложение | Этот адрес относится к самому устройству. Для телефона нужен HTTPS-туннель; настройка и проверка Telegram ещё предстоят. |

Для первой установки с нуля используйте [README.md](README.md): там сохранены установка backend, подготовка БД и демо-тарифов, а также добавлена сборка интерфейса.
